# 企业级可验证商品生命周期网络
## 系统架构设计文档 v1.0

**技术基座：Polygon CDK + DID/VC + ZK/Plonky3 + MCP/AI Agent**  
**文档日期：2026-08-19**

---

# 1. 架构目标

本系统面向猪肉、鱼、水果、工业产品、大闸蟹、奢侈品等真实世界商品，建立一个**企业级、隐私保护、多监管机构、DID/VC、ZK、AI/MCP 原生的可验证商品生命周期网络**。

核心目标：

- 商品唯一身份
- 批次与独立单品追踪
- 生产、加工、物流、仓储、零售、C2C 全生命周期
- 所有权与 Custody 分离
- DID 数字身份
- Verifiable Credentials
- 多监管机构与 Regulatory Domain
- 隐私保护与 ZK 合规证明
- ERP/MES/WMS/TMS/IoT 自动接入
- MCP/AI Agent 自动产生业务 Intent
- Agent DID + Capability 权限
- Polygon CDK 链上状态与 Ethereum 结算

# 3. 核心架构原则

## 3.1 链上不是传统数据库

链上保存：

- 商品/批次/单品状态
- Ownership 状态
- Transfer Event
- Commitment / Hash
- Credential 状态
- Policy Version
- ZK Proof / Verification Result
- State Root
- 审计锚点

链下保存：

- 完整 VC
- 检测报告
- ERP 原始数据
- IoT 原始数据
- 合同、发票
- 商业价格
- PII

---

## 3.2 AI 不是可信事实来源

AI 可以：

- 理解自然语言
- 编排企业业务
- 调用 MCP
- 创建 Intent
- 查询数据
- 请求生成 ZK Proof

AI 不应该直接决定可信事实。

可信来源应来自：

```text
ERP / MES / WMS / IoT
检测机构
监管机构
Credential Issuer
授权人员
```

---

## 3.3 MCP 不直接拥有无限链上权限

正确执行链：

```text
AI
 ↓
MCP
 ↓
Intent
 ↓
Schema Validation
 ↓
DID / Capability Authorization
 ↓
Regulatory Policy
 ↓
ZK Proof
 ↓
Polygon CDK
```

MCP 是 **Intent Producer / Agent Interface**。

\[

- \(P\)：Product State

\[

=

必须满足：

\[
Verify(Proof)=1
\]

以及：

\[

# 63. 架构结论

系统的核心不是单独的 Blockchain、ZK、DID、VC 或 MCP，而是形成一个完整可信执行闭环：

```text
企业系统 / IoT
       ↓
      MCP
       ↓
     Intent
       ↓
    DID 身份
       ↓
     VC 声明
       ↓
  Regulatory Policy
       ↓
Capability / Authorization
       ↓
     ZK Proof
       ↓
    状态转换
       ↓
  Polygon CDK
       ↓
   Ethereum
```

最终产品不是单纯的“商品溯源链”，而是：

> **可验证商品身份 + 可验证生命周期 + 可验证所有权 + 可验证监管合规 + 隐私保护 + AI 自动操作的企业级商品网络。**
